# 四种思考模式的新测试用例

## 为什么换题

旧题是解释 API 性能测试，比较简单。本次改为有确定最优解的整数采购优化题，同时涉及三种资源、库存、最低数量、组合约束、按类型计费和条件优惠，更适合观察不同思考档位的差异。

题目见 `思考模式测试题.txt`。一键对比程序 `compare_modes.py` 默认读取该文件；四组各5次，关闭/low/high/max，其他配置保持相同。`benchmark.py` 的独立默认题不变；单独调用时使用 `--prompt-file .\思考模式测试题.txt`。

## 运行

在 PowerShell 执行：

```powershell
Set-Location '.\api_benchmark'
python .\compare_modes.py
```

追加 `--dry-run` 仅查看计划，不发送请求。程序如找不到环境变量，将在交互终端中提示隐藏输入密钥。

## 历史与缓存

脚本每次请求只发送一条当前 user 消息，没有历史对话、会话 ID 或上一轮答案，因此之前运行过旧题不会自动带入聊天记忆。关闭思考是本次请求的显式参数，不是模型因为记住答案自行关闭。

服务器可能复用匹配前缀的计算缓存；这与记忆答案不同。脚本在每个输入开头插入不同编号以减少命中，但无法保证未命中。看 results 中实际 cache_hit_ratio，而不是凭重复次数判断。新题也不能证明从未出现过类似训练数据。

## 标准答案（不会发送给模型）

通过枚举 A=0..5、B=0..6、C=0..5、D=0..4 的全部1260种组合并检查约束，得到115个可行解。

唯一最低费用方案：A=2、B=6、C=3、D=0。

- CPU：2×8+6×12+3×4=100。
- 内存：2×16+6×12+3×32=200。
- 存储：2×40+6×30+3×20=320。
- 总包数：11；C=3≥2；B+D=6；均不超过各类库存。
- 基础货款：2×37+6×41+3×35=425元。
- 处理费：购买了3类，3×9=27元。
- A不足3包，无优惠。
- 最终费用：452元。次低可行费用为469元。

## 结果如何解释

性能结果仍保存为 results/compare_时间编号/ 下的 comparison.md、comparison.csv、comparison.json。重点比较正文延迟、总耗时、推理token、费用、失败与截断；新题结果与旧题不能混成同一组。

当前 benchmark.py 不保存正文、不自动判分。这个标准答案供人工验证或后续增加质量评分使用，不能据现有性能报告声称某档正确率更高。单道题每档5次只适合初步观察，不代表通用推理能力；关闭思考也可能算对，不保证max一定更好。
