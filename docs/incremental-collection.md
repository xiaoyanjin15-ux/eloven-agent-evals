# 逐条采集和试跑确认

启动服务后刷新页面，在开始测试弹窗选择测试集和用例，再配置：

- **结果保存目录**：填写运行服务的本机绝对目录，留空使用项目 `artifacts/batch-批次ID/`。
- **回填起始列**：例如 `J`。留空自动追加空白列；文字和截图同时保存时使用两列。已有内容的目标单元格会被拒绝，避免覆盖测试题或答案。
- **保存形式**：回答文字、截图或两者都保存。

每条用例完成后立即更新并保存结果 Excel，再发送下一题。写入使用临时文件替换，原始上传文件保持不变；多份源 Excel 会分别生成结果副本。超过 Excel 单元格长度限制的回答另存完整 TXT，并在单元格中注明位置。截图可在 Excel 中查看，完整尺寸原图可从执行记录打开。

选中的用例超过两条时，前两条完成保存后自动暂停。检查弹窗内的回答、截图链接和结果文件，点击“确认，继续剩余用例”后才发送第三题。点击“停止并保留结果”结束本次任务。只选一两条时直接完成。

下载链接和实际保存路径在执行进度中展示；批次详情保留所有结果文件的下载入口。查看本地结果后请关闭 Excel/WPS，避免占用文件导致后续写入失败。保存失败会停止执行，已写入的文件及数据库中的原始回答保留。

新导入用例会记录其来源 Excel。旧用例仅在原始行与问题匹配时使用项目现有源文件；如果提示来源不匹配，需要重新导入对应测试集。任务的暂停等待状态保存在服务内存中，重启服务后不能直接继续原任务，应根据已保存结果选择剩余用例重新执行。
